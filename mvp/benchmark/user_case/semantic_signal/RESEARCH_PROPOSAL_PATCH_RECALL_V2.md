## 2. 核心难点 = 采纳门控（不是召回本身）

patch top1 分数**不能单独做门**：错误位置分数同样高（t1r02 错排 0.964、t2r07c 错排 0.947）。
门控设计空间（门控探针 `probe_patch_gate.py` 实测后定）：

| 候选信号 | 已知数据点 |
|---|---|
| patch top1 与主定位偏移 | p14 12s / p26 9s / t1r02 6s / t1r14d 40s / t2r05a 2774s / t2r05b 342s |
| patch 分数差（top1 vs 主定位处） | 待测（关键区分信号候选） |
| CLS 相似度差（top1 vs 主定位处） | 待测 |
| patch 绝对分 | 无判别力（错误位也 0.94+） |

**设计约束（门控必须同时满足）**：
1. p14/p26 被采纳（救回）；
2. t1r02/t1r14d/t2r07c 不被采纳（反向防护）；
3. 对照组（现严格命中段抽样）零接触或仅原地强化。
