# 立项提案：突破零训练约束 —— 监督化细粒度判别嵌入（T1 可行性探针先行）

> 日期：2026-09-06 ｜ 状态：**已立项（用户拍板「突破零训练约束」）**
> 性质：训练路线首次开闸。分两段：T1 离线可行性探针（零 runtime）→ 达标后 T2 runtime 化
> （bump feature_version + 全量重建 + 三指标验收）。

## 1. 为什么解禁（前提变化总结）

1. 失败族已收窄到**特征粒度天花板**：同场景相邻镜头偏移（±3~13s）+ 内容相似远距错配，
   共 22 条非严格命中；外观/局部/上下文/多模态零训练路线全部证伪（M1-M8 重跑矩阵 + 今日
   context/patch 探针）；
2. patch v2（+3）证明「同场景相邻时刻」**存在可提取的判别信号**，只是 CLS 空间里太弱——
   训练的作用就是把这个弱信号放大成主信号；
3. 数据资产完备：四片 3.1 万索引帧 + 场景表（2.mkv 699 场景）+ 139 条 verified GT +
   数千条高置信帧级对应关系（HIT 段）——**自监督/弱监督训练数据不需要人工标注**。

## 2. 方法阶梯（从便宜到贵，逐级判决）

### T1a（判决性闭式探针，分钟级）—— 最优线性判别投影
LDA（按场景标签的类间/类内散度）求 384 维空间里**理论最优的线性判别投影**，在投影后空间
重测 22 条失败案例的 GT 排名 + 易例回归。
- 若 LDA 都救不动 → 线性可分性不存在，纯对比训练大概率也不行 → 关闭或转向非线性/更大容量；
- 若 LDA 显著救回 → 信号存在且线性可提取 → 进 T1b。

### T1b（对比微调探针，CPU 小时级）
冻结 backbone + 训练非线性投影头（384→MLP→384，InfoNCE，hard negative = 时间相邻场景帧）。
自监督标签 = 场景表（同场景为正，相邻场景为难负）。
- 在留出片（hold-out film）上验证泛化，防「背了答案」；
- 对比 T1a：非线性是否带来线性没有的增益。

### T2（runtime 化，仅 T1 正面后）
投影头并入特征管线（或全量微调）→ bump feature_version → 四片全量重建 → 三指标验收
（严格 ≥117 且零回退）→ 才进产品。

## 3. 数据与监督设计

| 信号 | 来源 | 用途 |
|---|---|---|
| 场景表 | 索引 scenes.npy（2.mkv 699 场景等） | 类标签（正样本组） |
| 时间邻接 | 1fps 索引天然时间序 | **hard negative**（相邻场景 = 失败模式本体） |
| verified GT | 139 条镜头级条目 | 评估集（不进训练，防泄漏） |
| 高置信对应 | HIT 段的帧级对应 | 可选强化监督（T1b） |

已知陷阱（设计时规避）：场景表来自旧 CLS 切分，粒度可能粗于 GT 镜头 → T1a 的 LDA 上限
受此限制；若 T1a 边缘，T1b 改用「时间窗口伪类 + GT 窗监督混合」。

## 4. 风险

| 风险 | 对策 |
|---|---|
| 灾难性遗忘（训练破坏原检索空间） | T1 用独立投影头不动 backbone；T2 全量微调才碰 backbone |
| 训练数据粒度错位（场景表 ≠ 镜头） | T1a 闭式上限先探明；混合监督备选 |
| 过拟合 4 部片 | hold-out film 泛化评估 + 易例回归检查 |
| 本机算力（无 CUDA） | T1 全部 CPU 可跑（特征已缓存）；T2 若需 GPU 训练再议（CI/云） |

## 5. 验收标准（T2 进 runtime 门槛）

1. 22 条失败中 ≥1/3 转严格 HIT，且易例零回退；
2. 四片三指标严格 ≥117 且零回退（新特征空间重跑）；
3. hold-out 泛化成立（训练片外也有效）；
4. bump feature_version + 全量重建流程跑通。
