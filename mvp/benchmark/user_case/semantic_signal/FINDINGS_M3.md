## 探针设计

- **模型**:`clip-ViT-B-32-multilingual-v1`(sentence-transformers, 512 维, 图片+文本同一空间,
  支持 test4 法语字幕)——这是「字幕语义→原片场景」向量索引的正确形态(跨模态,无需逐场景 VLM 描述)。
- **流程**:原片每个候选场景抽 3 帧 CLIP 编码(均值聚合) → 编辑段字幕文本 CLIP 编码 →
  字幕向量 × 场景向量余弦 → 候选子集内排序。对照 CLS(场景指纹)排序。
- **案例**:p26(夜读)/p08(兄弟)/t3r12(重复)/test4(同质)/p01(易例)。

## 结果 = 字幕-CLIP 检索无判别力(全部案例)

| 案例 | 字幕-CLIP 真值最优 rank | top5 相似度跨度 | 解读 |
|---|---|---|---|
| p26 夜读 | 2/8 | **0.7674→0.7652 (Δ0.002)** | 相似度挤成平台, 排序≈噪声 |
| p08 兄弟 | 3/7 | 0.8948→0.8939 (Δ0.001) | 同上 |
| t3r12 重复 | 1/7 | 0.8388→0.8381 (Δ0.001) | 正确(但跨度仍极小, 偶然性高) |
| test4 同质 | 2/8 | 0.8609→0.8584 (Δ0.002) | 同上 |
| **p01 易例** | **5/7** | 0.8809→0.8772 | **被字幕推到接近垫底(比随机差)** |

**核心证据**:
1. **CLIP 字幕-场景相似度对同一事件外观族全域饱和**(Δ<0.003)——CLIP ViT-B-32 的
   文本-图像对齐在「同质外观/兄弟机位/重复镜头」这些**外观近同**的候选之间**无区分能力**。
2. **易例 p01 回归**:字幕"防止可怕的怪物逃出"是**故事级抽象描述**,与金属球装置画面
   并不逐帧对应 → 字幕反而把正确场景推到 5/7。说明字幕是**叙事文案**,不是**画面描述**。
3. 与 M2 对照:M2 的 VLM EVENT-MATCH(强模型、逐窗、昂贵)在 p26 有弱方向性(3/3 vs 1/3);
   M3 的可规模化 CLIP 索引(弱模型、批量、便宜)**没有**——**「能建索引」的形态恰恰没有判别力**。

## 诚实边界(必须声明)

1. **本探针的 CLS 对照基线不公平**(`rep=真值场景指纹均值`作查询 = 循环对照,天然偏向真值,
   故 CLS rank 显示 1)。**结论不依赖该基线**——负面证据来自字幕-CLIP 的**绝对相似度平台
   (Δ<0.003)与易例回归**,与 CLS 对照无关。
2. CLIP ViT-B-32 是较弱的跨模态模型;更强模型(SigLIP/大 CLIP/VLM 批量 caption)或可改善,
   但 M2 已证最强形态(VLM)也只是 p26 单例弱信号。**证据总体不利**。
3. 候选子集由真值+干扰构造,未覆盖全索引(699+ 场景)全局排名;但相似度平台表明全局排名
   同样是噪声(无区分度则任何排序都是随机的)。

## 净结论

1. **方向 C 的「可规模化向量索引」形态 = 证伪**:CLIP 跨模态字幕检索在失败族上无判别力
   (相似度全域饱和),且易例回归。**字幕语义召回无法用「向量索引」落地**——这是方向 C
   唯一被完整测过的形态(M1/M2 的 VLM 是昂贵逐窗,不是索引)。
2. **与 M2 合看的方向 C 全貌**:
   - 昂贵 VLM 逐窗(M2): p26 单例弱正向(3/3 vs 1/3)——不可规模化,样本单薄
   - 可规模化 CLIP 索引(M3): 无判别力(Δ<0.003),易例回归——**证伪**
3. **为什么字幕语义召回不可行(机制归因)**:解说字幕是**故事级叙事文案**(编辑者写的旁白),
   不是**画面级描述**;它与画面内容的对应是**松散/解耦的**(test4 证明连事件都无对应,
   p01 证明抽象文案会带偏)。「字幕→画面」不是可靠映射,故不能作为召回信号。
4. **至此方向 C(多模态语义)证据链完整**:M1(判定)证伪、M2(召回,VLM)单例弱、
   M3(召回,可规模索引)证伪 → **多模态语义层不构成可用的第二信号**。
5. 零 runtime 改动;三指标 39/41 不受影响。

## 交接(方向 C 关闭建议)

- **方向 C = 关闭(有据)**:可规模索引证伪 + 昂贵 VLM 仅单例弱信号 + 机制归因明确(叙事文案≠画面描述)。
- 用户此前的怀疑「早期纯视觉决策是否错过多模态红利」得到**最终回答**:多模态语义(方向 C)
  是**唯一曾被遗漏的通道**,现已完整验证——**判定层证伪、召回层(索引)证伪、召回层(VLM)单例弱**。
  **没有可靠的多模态红利可回收**,「纯视觉 + 特征上限」是经得起多模态验证的结论。
- 剩余未探索方向(如仍想推进):更强视觉 backbone 的**局部 patch 级召回 + 两阶段检索**
  (纯视觉, 与多模态无关)——但 M3 的教训是**可规模化的弱信号优于昂贵的强信号**,
  局部 patch 若也只在昂贵形态有效,同样不落地。
