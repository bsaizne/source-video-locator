# ⑩ p08b 复核（v4 GT 口径, 2026-09-04）——「patch 救回兄弟机位 32→2」= 污染残留, 作废

> 性质: 研究侧复核（零 runtime 改动, 用存档数据 + v4 GT 重判）
> 起因: NEXT_STEPS ⑩ —— M5 的 p08b 用 1048-1050 当真值(= p38 旧 GT 区), 若编辑段真值=1108-1110,
> 则「patch 救回兄弟机位 32→2」存疑, 需用 v4 口径复核这个早期正面结论。

## 一、结论: M5 p08b 的「32→2」是错误 GT 的污染残留, v4 口径下作废

- M5 p08b 编辑中心 13.9s（= p08 编辑段 12.6-14.3 内部）, 真值窗取 (1048,1050) 士兵特写;
- **v4 GT 证明该编辑段正确位置 = p08 的 1108.15-1109.1**（用户/A 段裁决 00:18:28:15-00:18:29:10）;
- (1048,1050) 恰是 **p38 旧错误 GT 区**（v4 已删 p38, 且旧真值 1048 本身错, 正确=1108-1110）;
- 因此 M5「patch 把士兵特写从 CLS 32 拉到 patch 2」匹配的**不是编辑段的真实来源**,
  而是「错误但相似的士兵特写窗」——与 M6 v4 的 p38 半边作废结论一致。
