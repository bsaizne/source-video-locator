1. **子镜头识别可靠**: 编辑侧 DINOv2 帧级相邻余弦距离, 同镜头内 <0.05、镜头边界 >0.7,
   区分度极好; 阈值取 0.5 左右即可干净分离（6fps 采样, 无需全帧）。
2. **蒙太奇段应逐子镜头查询**: 段首 Jacob 子镜头独立查询命中 GT 2931（整段均值命中 3303）。
   **单均值查询 = 语义稀释, 定是缺陷**; 逐子镜头查询能恢复到正确子镜头。
3. **修复方向**: 对蒙太奇段, 用帧级相似度突变识别子镜头, 逐子镜头独立查询/定位,
