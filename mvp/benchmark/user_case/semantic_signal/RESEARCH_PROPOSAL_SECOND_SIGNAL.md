## 3. 候选方向（未证伪，按推荐优先级）

### 方向 A：场景实例身份建模（最推荐，直击「哪个实例」）
- **假设**：原片可组织成「事件实例」单元（一场对话 = 1 实例，多机位 10 次切镜同属）；
  给实例学身份嵌入（聚合语义），兄弟机位落同一实例、异事件不同实例 → 消解 p08 歧义。
- **与已证伪的区别**：已证伪的是「外观/帧级」信号；身份嵌入是**聚合语义**（事件级），
  信息层级更高；GT 双真（p08+p38 verified）恰是现成训练/验证标签。
- **可证伪探针**（研究侧 ~1 天）：
  - P1：2.mkv 用 scenes 表 + DINOv2 特征做事件级聚类（场景内多机位合并），验证
    p08 场景(1106-1121)与 p38 场景(1041-1061)能否聚为同一「对话事件」身份，且与邻近事件可分；
  - P2：事件身份嵌入能否把「编辑段 → 正确事件」排序从 CLS 名次提升到 top-1（p08/p08b/t3r12）。
- **验收**：P1 聚类纯度 + P2 名次改善；三指标不回退（仅确认进 runtime 后测）。
- **风险**：聚类边界难定；可能把 CLS 失败平移成聚类失败——这正是探针先行的原因。

### 方向 B：剪辑叙事结构（sequence 级全局对齐，中等，需谨慎）
- **假设**：编辑片按源片时间轴单调展开（test1/test3 实测强单调）；失败歧义在
  「整片序列视角」下可用叙事位置消解。
- **为何谨慎**：dinov2_ta（DINOv2+序列对齐）曾 blocked（total_pred=0）；VCSL/VTA 零正面证据。
- **可证伪探针**：test1-4 结果批编辑段顺序 vs 原片场景表单调性分数（正确段 vs 失败族对比）；
  失败族序列位置与候选分布有系统性偏移 → 有戏，否则证伪。
