## Part C — 冲突段邻域内容证据(新发现,唯一可行的立项方向)

t3r10 局部 CLS 曲线(编辑 55.5-57 查询,原片索引 430-470s 每秒 max sim):

- 错位区 447-449:峰值 **0.870**(现主定位,兄弟实例压制)
- 真值区 441-443:峰值 **0.731**(独立实质证据,处于 r9@440-442 与 r11@447.5+ 的空隙)

含义:r10 型错误**不是"真值无证据"而是"兄弟实例得分压制"**。现有 seq DP 修不动它
是因为候选池受限(真值候选不在池里)。由此得出可实施方向:

> **冲突触发邻域扩池 + 时序一致联合重排**:当某段主定位与相邻已 claim 段发生
> 高重叠冲突时,在空隙邻域(±15s)从索引扩池补候选,对该段(不全局)做带时序
> 罚的联合重排。r10 会落向 441-443(证据 0.73 + 时序空隙一致);r6 不受影响
> (其位置本身就是自己的证据峰,无更强竞争者)。

边界:p08/p08b(真值 0.81 vs 错 0.83,margin 0.02)与 p26 仍在可分范围之外 =
特征上限不变,本方向只覆盖"有实质次强证据的错位族"(test3-r10 实锤,r16 窗口
偏移同类)。

## Phase 24 实施结果(2026-08-30 深夜,用户拍板 A 立项后)

**实现**:`engine/localization/conflict_rerank.py`(纯函数)+ `locator_service._apply_conflict_rerank`
(接线于 temporal repair 之后)+ PipelineConfig 5 旋钮(`conflict_rerank_enabled` /
`conflict_max_mover_width_s=8` / `conflict_overlap_min_s=0.5` / `conflict_alt_min_sim=0.60` /
`conflict_max_drop=0.25`)。

**机制(几何触发 + 内容证据接受 + 无主张子区间落位)**:
1. 触发 `find_span_conflicts`:mover 宽度 ≤8s、与**编辑序相邻**段定位重叠 ≥0.5s、
   mover 置信分 ≤ 重叠邻居(非相邻复用重叠不触发——r6/r8 与 r10/r11 几何同构的可分点)。
2. 落位 `best_free_span`:空隙窗(prev.end, next.start)扣除**全部**段 claim 后的无主张
   子区间内分别 relocate 取最优 sim——整窗 relocate 会被非相邻合法 claim 整单否决
   (实机实证:seg10 候选 (446,448) 撞 r5 claim (445,447),真值区 (442,444) 被埋)。
3. 接受 `accept_repair`:候选 sim ≥0.60 且 cur−alt ≤0.25;修复 = 原主定位挪
   `original_segments` 留痕 + reason `conflict_rerank`,置信档位不变。
4. 处理顺序 = mover 置信分升序(弱主张先让位),每次用当前 positions 重算空隙(级联安全)。

**验收**:
- 后端 206(+19) + api 58 全绿;未打包(长期规则)。
- 2.mkv GT v3:`39/41 严格召回、FP 2/4、支撑 91/137`——与基线一致,零触发(flagged=[]),
  机制惰性;test1/2/4 同样零触发 → 零漂移由构造保证。
- **test3 E2E 实锤:r10 自动修复 447-449 → 442-444**(中心 443,人工真值 ≈444.5 ±1.5s;
  与 r11 的重叠消除),r9/r6 及其余段零扰动。对照图 `second_signal/r10_fix_verify.jpg`
  (新旧行同景重复镜头,单帧视觉难分 = CLS 兄弟混淆形态;以人工裁决真值为仲裁)。
- r10 不再需要结果页手动替换;该修复只影响"编辑序相邻重叠且有实质次强证据"的段。

**边界**:p08/p08b(真值 0.81 vs 错 0.83)/p26 仍在特征上限内,本机制不覆盖(其真值区
无被压制的次强证据峰);r16 型窗口偏移若满足触发条件可受益。
