## 7. 计划项 1 执行结果：ISC margin 门标定 = 判负关闭（2026-10-06 夜间批补）

> 原「ED 子镜头切分对齐」立项经材料复读修正：t1r08c/t1r12a 非子镜头族，而是 **ISC margin
> 卡门**（探针口径 0.0457/0.0391 < 0.05 门）。按门标定路径执行，两级探针后判负。

- **第一级（全量 0.035 臂，`probe_isc_margin35.py`）**：2mkv 实跑 2 行翻转，
  逐帧读图裁决 = row23（offset 1.5s）**真增益** + row77（0.9s 窄段 HIGH 被**远跳 56.6s**）
  **真损失** ⇒ 亚门分（<0.05）不可作远距重锚证据（历史「窄窗豁免放回假定位」同型）。
- **第二级（近场限定设计）**：offset ≤3s 才降门。实现+单测阶段发现**机制级否证**：
  `_score_mid` 是**评分窗内取 max**（窗 = mid ± (w/2 + ISC_TOL_S=1.5s)），任何距主 ≤3s 的
  峰几乎必落主定位评分窗内 ⇒ main_score 已包含峰分 ⇒ **margin 恒 ≈0，近场亚门无可达面**
  （单测实证：近场宽扫峰进主窗后 0.02 margin 归零不触发）。探针口径的 margin（点评分）
  与 runtime 口径（窗 max）**不可比**——这是本次的口径错位教训。
- **裁决 = 判负关闭（有据）**：① 全量降门不安全（真损失实锤）；② 近场降门无可达面
  （机制否证）。t1r08c/t1r12a 的真救回需要换评分几何（如主分排除峰侧样本/锚点级评分），
  属扫描语义变更，与「扫描行为缩减」同一立项层级，**不在本轮范围**。
- **工作区处置**：按「判负不进 runtime、不留通道」纪律，isc_refine/config/locator_service
  改动与单测已全部回滚（后端 540 OK 复验）；探针脚本保留作证据
  （`probe_isc_margin35.py` / `probe_isc_subgate_ab.py` + `work/isc_margin35/`）。
