## D. §C 的定性更正与修复结果（同日续32）

**更正**：§C 初稿把缺陷写成「`source_merge.py` 切点不互斥」——**错**。该产品只 concat 给定文件、
从不做切分；重叠两半是**验收夹具** `accept_source_merge_2mkv.py` 的切法（part2 用 `-ss key_t` 起切，
copy 语义下落点早 ~3.4s）。产品代码无缺陷；缺陷在夹具 + 验收覆盖边界。

**夹具修复（已落地）**：
1. part2 改以 **part1 实际末帧时刻**（`last_video_end`，末视频 packet pts+duration）起切 ⇒ 两半互斥；
2. 新增互斥性硬断言 `|part1+part2 − 原片| ≤ 0.5s`（旧重叠 +3.42s 在此即被拦下）；
3. 新增**时间轴同一性常驻锁**：拼接点前 δ 必须 = 0、拼接点后 δ 必须是 ≤0.5s 的**常数**
   （沿全片 8 个采样点、同 t 帧逐字节比对；δ 随 t 变化 = 有重复/缺帧）。
   首版锁写成"同 t 逐字节相等"过严（copy-concat 容器粒度做不到），改为"位移恒定"才是正确形态。

**重跑结果**（`work/merge_accept/rerun_20260930b.log` + `timeline_shift.json`）：
part1=3837.0 / part2=3830.7 / sum−原片=+0.2s；拼接点前 δ=0（3 点），拼接点后 **δ 恒 = 0.167s**
