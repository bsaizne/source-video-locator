### 10c. 结论（本轮最终定案）

1. **生产管线不需要 P0**：生产主 span 起点本来就是 moment 级精度（帧级簇 + finloc），
   「锚不准」是 TN 场景 span 复现管线的特有问题，不随移植转移。沙盒 +6 的收益在生产口径下归零。
2. **默认关维持正确**：模块+旋钮保留为基础设施（未来若定位改动劣化起点精度可开启）；
   开启代价 = 定位耗时 +45%~130%（2mkv OFF 700s vs ON 1615s 含索引重建；test1 530→772s）。
3. **竞品对标主线收官**：全局层语义（主线锁定/偏移投票/路径 DP）确认为管线级属性；
   移植路径（豁免→移植→回归→定案）全程走通；生产零收益本身即结论——**我方生产在"起点精度"这一环
   已达竞品密集复核后的水平**，端到端差距（若有）不在这一层。
4. 未竟：UI/剪映/PR 导出验收因打包需授权未做（默认关状态下无行为变化，风险为零）。
