# FINDINGS — 竞品关键功能差距分析（2026-09-26 续10b）

> **前提（用户实测，不再质疑）**：竞品在相同素材上端到端**更好**。本文件回答：差距来自哪些**可命名的关键能力**，
> 每条附证据与建议动作。材料源 = 竞品 profile 常量（27+7+4 项字节确证）+ FINDINGS/01-12 + B/D 段复现实测 + 我方全部历史探针。

## 0. 一句话总览

竞品的优势不是一个单点，而是一条**组合链**：**学习式切分（TN）→ 每场景关键帧代表（而非均值）→ patch 全局双通道加权 →
场景路径一致性 → AKAZE 几何校验**。我方在每一环都有"对应物"，但每一环的**形态**都不同；单独看每环差异都不致命，
**链起来就是用户看到的端到端差距**。我方历史实验反复出现"单环替换无效/变差"（A1 −16、A2 无增量、patch 融合零改善、
时间轴先验零触发）——因为每次只换一环、其余环节还是旧形态，组合效应从未被测过。

## 1. 差距清单（按预期影响排序）

### G1 查询单元代表帧：每场景 5 关键帧 + 长场景 1s 加密（cap 16）⇔ 我方整段 2fps 均值
- **竞品**：`keyframes_per_scene=5` / `long_scene_keyframe_interval_seconds=1.0` / `long_scene_max_keyframes=16`（字节确证）。
- **我方**：整段均匀 2fps 采样后**取均值**查询单元表征。
- **证据**：我方 V5 非 HIT 分诊「查询稀释 5 例」；蒙太奇单均值稀释早在 FINDINGS_SUBSHOT_QUERY 证死（t2r02b：正确子镜头
  sim 全场最低 0.625，均值漂移到洒水器）；16/16 逐子救回但败于"无 GT 的子镜头选择信号"——**竞品用 TN 场景边界 + 5 关键帧
  恰好就是这个"无 GT 选择信号"的工程答案**。复现 p10 拒识（4 镜头段）同机制。
- **动作**：「**细切分 + 关键帧化**」混合探针——查询单元照旧（保三指标可比），单元表征从均值改为段内 5 关键帧（多查询取最优）。
  零新依赖、不 bump feature_version（编辑侧不落索引），四片回归验收。**这是复现里已被验证跑通的组合（0 内容性错误）。**

### G2 学习式切分（TN）的正确用法：输出层 + 段内子单元，而非"替换查询单元"
- **竞品**：TN（a01，模型字节级验同一）做全流程场景边界；切分质量盲判 = 对方独有切点 27 真/0 假，我方 6 假 + test2 漏切 13。
- **我方历史误读**：A1「TN 替换切分」−16 让我们关闭了整条 TN 线——但 A1 替换的是**查询单元划分**，牺牲了证据量；
  FINDINGS_TN_CUT_QUALITY_VS_METRIC 已证明：**我方三指标奖励"与 GT 段一致"，不奖励几何正确**——A1 的 −16 是
  指标口径惩罚，不是产品价值否定；用户看到的边界质量恰是 TN 强处。
- **动作**：① 输出/展示层采用 TN 切点（用户可见，零指标风险）；② TN 切点作**段内子 span**（并集+就近优选，不删我方切点——
  TN 仲裁删除已被 Stage 1 否定）；③ 与 G1 合并 = 「TN 段内单元 + 5 关键帧」。

### G3 patch 通道是主力而非门控：`patch_top_k=100 × patch_weight=0.55` + `max_patch_tokens_per_scene=512`
- **竞品**：patch 与 global 0.45/0.55 加权融合（代码级互证 co_consts + retrieval.py）。
- **我方**：patch 仅做近场门控重排（patch_v2，权重地位低得多）。
- **证据**：我方融合探针（w 扫描）零改善——但那是**在我方池/均值查询口径下**测的；竞品条件下 patch 作用在关键帧单元 +
  场景 top-k 上，条件不同，**不能拿旧探针否定**。
- **动作**：G1 落地后（关键帧口径）重测 patch 权重扫描；若仍零增量则诚实关闭。

### G4 AKAZE 局部几何校验链路（我方完全没有）
- **竞品**：`feature_method='akaze'`、min_match_points 12/4、inliers 入候选表——对 top 候选做几何验证。
- **复现实测**：本口径下 on/off 差异仅 10/262 行（strict 门拒绝），**无增量无伤害**。
- **判读**：不是必需件；但它是竞品"敢给 HIGH 置信"的物理依据之一。优先级最低，G1/G2 有结论后再议。

### G5 场景路径一致性：`select_scene_match_path` / `resolve_consecutive_scene_offsets` + `continuity_tiebreak_bonus=0.02`
- **竞品**：连续查询场景间做路径级一致性优化（FINDINGS_TN_CUT_QUALITY §4.3 称其"定位更准的最可能来源，且与切分无关"）。
- **我方**：时间轴先验（候选生成级弱先验）实测零触发零增量——但那是**不同位置**的实现（我们做的是"带内竞争候选"，
  他们做的是匹配目标函数里的路径项）。
- **动作**：待其机器码逆向给出目标函数细节后对齐设计探针；短期不投入。

### G6 offset/DTW 精修门族（确证参数 7 项）——形态差异最小的一环
- min_support=2 / min_score=0.55 / tolerance 2 帧 / tie_margin 0.03 / DTW 64 样本 / start_window ±30 帧 / topk_rerank 10 / coverage 0.8。
- 我方 finloc/conflict_rerank 存在等价机制；**建议 C**（用确证门打我方 14 例"同池选错"）仍是待拍板项。
- 复现实测 t1r12a 型：rank1/rank2 分差 0.032 骑 tie_margin 边缘选偏邻接场景——**这类正是 G6 门族 + G5 路径项要治的**。

### G7 输出粒度（用户直接感知）
- TN 切点给用户的片段边界几何正确（0 假切点）；我方 6 假切点 + test2 漏切 13 用户可见。
- 动作即 G2①，最快见效、零风险。

## 2. 为什么我方历史实验没发现这些（方法论教训）

1. **三指标的口径盲区**：指标奖励"与 GT 段一致"（切分参数是朝 GT 调过的），几何正确性完全不可见——
   竞品的切分优势在我们的指标里是**负分**（A1 −16）。用户的产品观察与我们的指标第一次系统性地指向相反方向。
2. **单环替换 ≠ 组合**：A1（只换切分）、A2（只换排序）、融合探针（只换权重）都是"新环+旧链"，组合效应从未测过。
   复现（全链照抄）0 内容性错误 + 候选 top1/top2 命中，就是组合有效的正面证据。
3. **均值查询的稀释**被我们当成"已知局限"接受了两年，而竞品用"切分+关键帧"两个便宜手段就绕开了。

## 3. 建议立项（一个探针，三验收）

**「TN 子单元 + 关键帧查询」混合探针**（= G1+G2②+G7，研究侧先行、零 runtime、不 bump feature_version）：
- 查询单元划分不变（三指标可比）；单元内用 TN t050 切点切子段，每子段 5 关键帧独立查询，子段结果并集+就近优选；
- 验收：① 四片三指标不回退；② 蒙太奇稀释 5 例（查询稀释族）改善可见；③ 用户可见输出换 TN 边界；
- 风险与既有结论一致：**不做仲裁删除**（TN 仲裁已证伪）、不改我方索引。
