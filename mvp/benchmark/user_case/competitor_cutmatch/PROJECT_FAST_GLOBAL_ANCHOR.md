# 立项：快速全局锚定通道（fast_global_anchor）——"第二套复现"的最小证据形态（2026-09-28 用户拍板"立"）

## 1. 目标与证据边界

**目标**：main-span 单发起点精度向竞品复现链水平靠拢（同口径参照：我方 77/139 vs 复现链 100/139，
续10m，**推断级**——复现链=我方沙盒按竞品字节确证参数的重建，非竞品实测），生产三指标 119/139
不回退。

**为什么不搬"整条七阶段链"**：续10m 三臂归因已把价值定位得很死——
p0f 13 → DP 选路 only **5（−8，有害）** → DP+种子 16 → **种子叠加贪心 23（+10 全 MISS→HIT 零退化）**。
⇒ 全局层的价值**全在"锚定"（跨查询偏移投票共识种子），不在"选择"（路径 DP/ordered_search）**。
本项目移植的正是产出 100/139 的那个胜出形态（F1 采样 + F2 投票 + F4 种子叠贪心），
DP/ordered_search/recovery 明确**不在范围内**（已证伪或机制未确证）。

**已知不可外推项（诚实前置）**：
- 复现链跑在竞品口径特征库（224/3fps/官方 ViT-S）上；我方生产=518/1fps 源库 + 2fps 查询。
  **+23 是沙盒口径，不得假设可迁移**——P0 密集复核"沙盒 +23 → 生产零增益"就是前车之鉴。
  生产侧真实预期：介于已兑现的 +2（vote_prior，2fps 输入 + 4s 帽）与 +23 之间；验收门以实测说话。
- 竞品 quality weights（亮度/对比/清晰度）需要像素统计，我方 dense 缓存只有 embedding+时间——
  M1 先做**均匀权重**，质量权重作为独立消融腿（需扩缓存），不在首轮引入。

## 2. 与 vote_prior 的关系（增量定义）

现役 `vote_prior`（续11，默认开，+2）= 2fps 段内采样帧投票 + support≥0.2 + **max_shift≤4s**。
主病灶"同场景内选错时刻"（图证 18–21s 偏移）**结构上被 4s 帽挡死**——这是本项目存在的理由。

`fast_global_anchor` 增量 = ① 输入换 **8fps dense 缓存降采样至 3fps**（票数×1.5，簇更稳，零解码）；
② **无位移帽**，代之以 **宽窗共识支持度门**（全体票落种子 ±1.5s 内 ≥0.5；窄簇 support 降到 0.1 只防
单票退化——1fps 库网格+3fps 查询的 proj 天然错开 0.33s，0.2 窄门是 2fps+帽时代遗留，M1 冒烟实测暴露
support 0.143 拒掉了正中种子 19.625s，机理修正非 GT 拟合）；③ 平移**保宽度**（大位移下 end 跟着走，
vote_prior 的小位移"只移起点"语义在 20s 级移动下会扭曲段长）。
启用时**替换** vote_prior 应用点（同一机制的超集，不叠加二次平移）。

## 3. 里程碑与验收门

- **M1（本轮）**：纯函数+旋钮（默认关）+挂接+单测 → **四片双臂生产回归**
  （arm0=现役基线，arm1=fast_global）：三指标（严格/场景/负例）+ **main-span 同口径截等长测量**
  （77 基线同判据）+ 全部翻转逐张读图裁决。**通过门**：main-span 同口径净增 ≥ +8 且三指标零回退；
  不达标 → 关闭留档（同 E1/E3 处置），**不得调门限凑数**（门限=工程先验，禁 GT 反标）。
- **M2（仅 M1 通过）**：质量权重消融腿 + 分散度门限敏感性（仍禁 GT 拟合）+ 打包验收 → 翻默认。

## 6. 竞品侧信息对照（2026-09-28 用户令"先检索竞品对应信息"后补）

权威出处：`FINDINGS_DOCSTRING_BREAKTHROUGH.md` §5/§9b（docstring 确证）+ `FINDINGS_FAST_GLOBAL_REPRO.md` §F1/F2
（沙盒复现记录）。竞品 coarse_retrieval 原始形态 =
「每个 3fps 解说样本**独立 top-k** → **0.05s 分桶加权投票** → OffsetCandidate
{source_start, coarse_score, support_count, support_ratio, offset_dispersion_seconds}」，
可靠性门 = **dispersion ≤ 0.35s + 支持率门**（0.35s = blob 常量确证；支持率门值未绑定）+
`min_valid_samples 2/3`（insufficient_samples 原因常量）。**无位移帽**——续11 的 4s 帽是我方生产安全加设，
去帽方向与竞品原形态一致 ✓。

| # | 竞品确证形态 | M1 实现 | 定性 |
|---|---|---|---|
| a | 每样本独立 **top-k** 汇总投票 | **top-1** 投票 | 已知近似（沙盒 F2 同款简化，k 值未确证）→ M2 消融腿 |
| b | 门 = dispersion≤0.35s（票集秒级 std）+ 支持率门 | wide_support(±1.5s≥0.5) + 窄 support≥0.1 | **我方自造**（宽窗语义是工程代理：竞品 dispersion 的票集定义未确证）→ M2 消融腿=补"宽窗内 std≤0.35"变体 |
| c | 3fps + 亮度/对比/清晰度**质量权重**（权重形状未确证，沙盒自择 0.2/0.3/0.5）+ 短镜头均匀补点 | 均匀权重（dense 缓存无像素统计） | 章程 §1 已登记 → M2 消融腿（需扩缓存） |
| d | min_valid_samples ≥3 | 帧数 <2 即拒 | 一行可对齐，M2 随消融腿一并 |
| ✓ | 0.05s 分桶 | 0.05s（复用 vote_prior_bucket_s） | 与竞品 coarse 一致 |
| ✓ | 无位移帽 | 无帽 | 一致 |
| ✗ | continuity_tiebreak_bonus / ordered_search / 路径 DP | 不搬 | 三臂归因已证"价值在锚定不在选择"（§1） |

`offset_bucket_seconds=0.5` 属 **local_refiner**（局部精排层）而非 coarse——与 0.05s 无冲突，
此前档案两处并列易误读，此处钉死。竞品 confidence 层的 `min_support_ratio=0.35` 是**置信输入归一锚**，
不是 coarse 采纳门，勿混用（续14 已核过）。

**对 M1 判读的影响**：双臂若 main-span 净增 <+8，除"口径不可迁移"外须先排除 a/b 两项近似所致，
M2 消融腿（top-k、宽窗 std≤0.35、质量权重、min 3）作为**唯一允许的补救轮**跑完才能下关闭结论；
全部门限调整仍禁 GT 反标。
