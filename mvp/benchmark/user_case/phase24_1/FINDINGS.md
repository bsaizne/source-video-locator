## 1. 探针①视觉几何一致性 = **证伪(核心)**

### 方法
低 margin 触发段等价条件:`patch_rerank.py` 的触发机制(`shot.span.width >= 0.6`)。查询侧 3 帧(编辑片 ed_t±0.4s)→ 每帧 patch tokens(1369,384,L2,37×37 网格);候选侧 = CLS top-40 ∪ 真值窗 ∪ 兄弟窗(逐帧)。对每帧对:`mutual_nn` 互近邻匹配 → `cv2.estimateAffinePartial2D`(宽松仿射,RANSAC)内点率 + `cv2.findHomography`(单应)内点率。判别逻辑 = 真值机位内点率高、兄弟机位(同场戏不同机位)内点率低。

### 结果(逐帧,`work/phase24_1_probe_results.json`)

| 探针 | 真值帧 HOMOG/INL | 兄弟帧 HOMOG/INL | 判定 |
|---|---|---|---|
| p08(1108, 兄弟 1048) | 1108: 0.331/0.286 | 1048: **0.506/0.411** | ❌ 兄弟反超 |
| p08b(1048, 兄弟 1109) | 1048: 0.488/0.398 | 1109: **0.752/0.405**, n_match=329 vs 78 | ❌ 兄弟压倒 |
| p26(2808-2811) | 2809: 0.676/0.576(rank 2) | 无兄弟;top 干扰 1692: 0.685/0.591 仍压过真值 | ⚠️ 不稳 |
| p01 / p04 / t3r12(易例/参考) | 几何 rank 1 | — | ✅ 与 CLS 一致(本就正确) |

### 归因(为什么证伪)
1. **多视图几何事实**:同一**刚性场景**从不同机位拍摄,patch 对应**仍满足单应约束**(平面近似)。p08/p08b 是同一场戏的相邻机位,场景内容刚性,兄弟帧的互近邻匹配能拟合出一个有效单应 → 内点率反而不低。**提案前提「不同机位 → 违反单一仿射」在刚性场景上不成立**,这是理论层的否定。
2. **帧对齐敏感**:1fps 候选粒度下,真值窗内 1108→1109 内点率从 0.33 跳到 0.85(>0.5 跳变);p26 同窗 2808=0.34 → 2809=0.58。信号对候选帧的精确时间对齐极敏感,现有 1fps 检索粒度下不可作为重排特征。
3. **n_match 偏置**:兄弟帧(场景更大/更广)产生更多互近邻匹配(329 vs 78),内点率归一化后仍系统性偏高。
4. p26 的 rank 2 是**假阳性信号**:第 1 名干扰(1692, 0.591)仍高于真值(0.576),无 margin;且同一 4s 窗内帧间方差极大,不构成稳定判别。

**结论:视觉几何一致性不能区分「同一镜头」与「同场戏兄弟机位」,不进 runtime。**

## 2. 探针②时序运动签名 = **证伪(方法学不成立)**

### 方法
查询(编辑)窗 ±1s 抽 8 帧 → 帧差能量序列(归一化);候选(原片)窗同法 → 皮尔逊相关 + L2。判别逻辑 = 真值窗运动签名与查询更相似(重复镜头剪辑节奏不同 → r12 可能有判别力;p26 静态夜读预期无效)。

### 结果
- 易例 p01: true_corr=**-0.868**(严重负相关)——连最简单案例都完全失败
- p08/p08b: -0.38/-0.26(负);p26: 0.444 但 margin=-0.325;p04: 0.643 margin=+0.02(勉强);t3r12: 0.359 margin=-0.018(无判别)

### 归因
**前提不成立**:编辑片是**快剪**(压缩比>1,已实测),窗口级帧差签名的时间轴与原片不是 1:1 对应;未先做时间对齐(DTW 等)的前提下做窗口比对是错位比较。而时间对齐本身又依赖检索出的候选(循环依赖),且「加速/减速失真」在导出全原速下本就不存在(此前已证伪)。

**结论:方法学不成立,不做修正性重试(除非引入独立的时间对齐信号,无来源)。**

**结论:投影头微调不立项。除非出现一个真正可分的新信号(场景身份/语义级),否则维持现状。**
