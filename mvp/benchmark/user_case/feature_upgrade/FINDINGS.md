# Phase 23-0 特征升级预研 FINDINGS(2026-08-30 晚)

**结论:ViT-B/14(更强 backbone)在实锤失败探针上无增益,部分探针反而恶化;不建议 bump feature_version 全量重建索引。**

## 背景

Phase 22 交接拍板(2026-08-30 晚):特征升级立项 / 暂不打包 / GT 暂不补。已实锤特征上限:p08/p26/test3-r12(同场景重复镜头互混)、test4 全片(同质彩色滑梯,检索最强 sim 仅 0.53-0.60)。交接单给出的两个方向:更强 backbone 或 patch 级检索。本预研在同一探针集上对照 **ViT-S/14(现役冻结基线)** vs **ViT-B/14(embed_dim=768, num_heads=12,权重官方 dinov2_vitb14_pretrain.pth,346MB,与冻结模型类参数化实例化、state_dict 键名完全匹配)**。

## 结论与建议

1. **DINOv2 家族内升规模(ViT-S→ViT-B)不解决"同场景重复实例 / 同质外观场景"互混**——CLS 与 patch 两条通路、7 个探针,零增益、一处明确恶化(p08b)。与 Phase 21 E21 已知结论自洽:该失败族的分辨率缺口不在特征容量,而在信号类别(实例身份/时序结构/音频等第二信号)。
2. **成本收益不成立**:bump feature_version 全量重建索引(5 部片 GPU 1-2h)+ 特征存储翻倍(384→768d)+ ONNX 资产 346MB(bundle 4 倍)+ 全套回归,换不来探针改善。**建议不重建**。
3. patch-max(ViT-S)在 p08b 上的险胜与 Phase 21 V3 一致,该信号已在 runtime(patch 重排),无新增空间。
4. 剩余失败族(p08b 类兄弟实例、p26 夜读、test4 全片同质)若要继续攻,方向应是**非外观第二信号**(场景实例身份、时序结构先验加强、音频指纹),属新研究阶段;或在产品层以诚实置信 + 手动替换兜底(test3 r10 即此路径)。

## 边界(诚实声明)

- ViT-B 侧为局部窗口嵌入(干扰窗由 ViT-S 全索引选出),非全片索引;但干扰集保守覆盖了 ViT-S 的全部最强混淆区,结论的方向性成立。
- 1fps 采样、518×518 输入、CPU 前向,与生产管线同口径。
- 未测 DINOv2-L/H(趋势外推无改善依据)与 DINOv3(需单独许可,不可直接下载)。
- t3r10 实验一窗口边界帧 447s 同时落两窗致 margin 恒 0(口径缺陷,已在实验二内缩修正);argmax 落点结论不受影响。
