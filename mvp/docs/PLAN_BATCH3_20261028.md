## 0. 范围与红线

- **范围**：① 抓帧/建索引耗时；② smart render 重启（`cfr_snap` + `bframes=0` + `setts`）。
- **红线**：
  - **任何改变像素值的改动都必须 bump `feature_version` 并全量重建**（4 片 ≈ 1.5~2h）——
    这类改动**不在本批**，需单独立项口令。
  - 不动 GT、不翻与本次无关的默认值、不出包、不 push（档案/代码提交按批次节奏）。
  - 每项改动必须自带「零语义」证明：同一输入的产物（`features.npy`/`times.npy`/`scenes.npy`）**逐字节相同**。

## 1. 侦察读数（2026-10-28 实跑，本机 12 核 / RX 6750 GRE）

2.mkv（1280×688 HEVC10），300s 窗，生产参数（像素预扫 10fps→160×90；特征嵌入 1fps 全分辨率）：

| 通道 | 墙钟 | 帧数 | 管道量 |
|---|---|---|---|
| 像素预扫（10fps，scale 160×90） | **10.18s** | 3000 | 124 MB |
| 特征嵌入解码（1fps，bgr24 全分辨率） | **9.51s** | 300 | 756 MB |
| 两遍**并发**（同一窗口，双线程） | **13.18s** | 3000 / 300 | — |

外推全片（7667s）：两遍串行 ≈ **500s**；并发 ≈ **335s**；DML 推理（1fps×7667 @10fps）≈ **766s**。

**⇒ 重要订正（对档案）**：`Known Issues` 与 §五 引用的「CPU 抓帧 78% / DML 推理 18%」**在当前配置下已过期**。
当前口径 ≈ **解码两遍 40% / DML 推理 60%**（1266s 量级，与档案 22~31min/片吻合）。

**⇒ 由此得到的杠杆排序**：
1. **两遍解码合并/并发**（本次改动，零语义）——上限 ≈ 250s/片（≈20%）。
2. yuv420p 管道——省的是 swscale+带宽，实测仅占嵌入通道 ≈ 2.9s/300s（≈6%），
   **且会改变像素转换路径 ⇒ 触发全量重建**，性价比不成立，**本批不做**。
3. 进程内解码（PyAV）——同样有像素一致性风险，未验证前不动。
4. DML 推理（60%）——受「batch=1 固定」约束，本批不碰。

## 2. 决策树（代价升序）

**B3-1 索引两遍解码并发（= 本批主项，代价 S~M）**
- 形态：`_scan_pixel_boundaries` 与 `_embed_stream` 由「先后串行」改为「并发」，
  以 `index_parallel_passes`（默认 **False**）控制，关闭时行为逐位不变。
- 前置可证伪检查：并发下两遍产出的 `times/scenes/features` 必须与串行**逐字节相同**。
- 成功判据：同一 300s 窗口，**串行 vs 并发**墙钟比 ≥1.25×，且产物 sha 相同、后端全套绿。
- 失败 → 回滚配置位（默认已是 False），记录读数，转 B3-2。
- 回滚代价：一个 config 行 + 一处调用点。

**B3-2 像素预扫与嵌入的单次解码（双输出管道，代价 M~L）**
- 仅在 B3-1 增益不足且用户认可「Windows 双管道」工程风险时开。
- 成功判据：单次解码耗时 < 两遍串行 × 0.6，产物逐字节相同。

**B3-3 smart render 重启（cfr_snap + bframes=0 + setts，代价 M~L）**
- 背景：10-26 已实现「copy 段 + 重编段」条件快路径，10-27 真片判负（test3：容器 4513 帧、
  **严格解码仅 1975 帧**、非单调 DTS/非法 PTS；AMF 与 libx264 均复现）⇒ 当时默认关。
- 本批要补的三刀（10-26 版**没有**）：重编段 `-bframes 0`、`setts` BSF 钳 DTS、
  CFR 时间基 snap；并用「严格解码帧数 == 容器帧数」作为硬门。
- 成功判据：test3 真片 on/off 两臂**严格解码帧数相等**、DTS 单调、逐帧内容对齐，
  且墙钟 < 现役 26s。任一不满足 ⇒ 维持默认关并留档。
- 失败 → 关闭 smart render（第二次），不再重试。

## 3. 口径与边界

- 计时必须**同脚本双臂、独占设备**（本机 12 核；测量期间不跑其它 GPU 任务）。
- 「零语义」证明 = 产物 sha 相同（不是"看起来一样"）。
- 建索引上限结论只对 1280×688 HEVC10 与 1920×800 H.264 两类素材成立，不外推到 4K/长 GOP。
