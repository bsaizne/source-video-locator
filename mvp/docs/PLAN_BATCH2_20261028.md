## 2. 决策树（代价升序；每步「成功→下一步 / 失败→动作 + 回滚」）

**B2-1 Drop-DTW（代价 S：纯 numpy DP，零解码，复用 test1 全部缓存）**
- 判据：跨镜头 21 行 `|err|` 中位 **< 1.00s**（臂2 现役单点精排）且全量 43 行不劣于臂2（中位 ≤0.85、≤1s 不降）。
- 成功 → 记 FINDINGS，进 B2-2；并在结论里写明「相对臂3 平 DTW 的增量」。
- 失败 → 关闭该候选（写读数），**不回退去调 drop 参数**（避免 sweep 过拟合），直接进 B2-2。
- 回滚代价：零（`rm -rf work/b2_20261028/dropdtw`）。

**B2-2 置信三件套（代价 M：需四片编辑侧特征各抽一次 + 全片相似度剖面）**
- 形态：AS-Norm cohort 归一 / k-reciprocal 互惠一致性 / KNN-OOD，三者**并行独立**打分，不合并成新公式。
- 判据（单侧）：在 147 条「判对」行上**降档数 = 0**（HIGH→MEDIUM 视为降档）的前提下，
  3 条真错行里至少 2 条被抬出 HIGH。
- 成功 → 建议接线（需另立口令，改 runtime）；失败 → 关闭三件套，登记「非饱和信号源仍缺」。
- 回滚：零（离线脚本）。

**B2-3 VQ2D 式窗口扩张（代价 M~L：需 dense 10fps 曲线，落盘无缓存 ⇒ 需重跑 dense 腿或用 1fps 代理）**
- 前置：先判定能否不重跑（检查 results.json 是否留 dense 剖面）。**不能 ⇒ 明确写「1fps 代理口径」**，
  并声明该代理只证「窗口形状」的相对增益，不外推 10fps 绝对读数。
- 判据：代理口径下「扩窗 vs 固定 ±4s」逐行起点误差中位下降 ≥10% 且不增假阳。
- 失败 → 关闭；成功 → 转生产前须 10fps 真跑再验一次（另一批）。

**B2-4 XFeat 退化加固（代价 L：需解码 + XFeat 重跑；仅 5 条退化段）**
- 面：`USAC_MAGSAC` + XFeat semi-dense + GMS 预过滤。
- 判据：6 条退化段（t1r14a/t1r15/t1r19/p28(pg03)/t2r04b + 已知 1 条）逐段误差下降且非退化段零回归。
- 失败 → 关闭；成功 → 与 B2-1 结果一起决定是否值得进 runtime。

## 3. 口径与边界（所有子项共用）

- 被量化量 = **素材起点** `candidate_start` vs GT `original[0]`（与 mAP@δ 尺子同口径）。
- 源侧 1fps ⇒ 单帧粒度 = 1.0s；**任何 <1s 的增益都在测量精度附近**，
  判据用中位 + 逐行赢/平/输，不用均值，不宣称亚秒结论。
- 每项实验必须内置**口径锁定断言**（臂1/臂2 复算 == 档案读数），否则读数不可比。
- 结论分级：`判正（可接线）/ 判负（关闭）/ 未决（样本或仪器不足）`，**不得只报相对提升**。
