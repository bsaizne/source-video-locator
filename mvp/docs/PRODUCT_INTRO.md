# Video Locator AI —— 产品介绍

> 把剪过的视频，一秒定位回原片。
> 剪辑片段反向定位工具 · 全本地处理 · Windows / macOS

---

## 一、它解决什么问题

影视解说、二创混剪、搬运比对……几乎所有二次创作都要面对同一个问题：

> **这段画面出自原片的哪一分钟？**

传统做法靠人眼逐段比对：一部两小时的原片配一条三分钟的解说，找齐三十个片段可能要耗掉一整天。Video Locator AI 把这件事变成**一次自动分析**——导入你的剪辑成片和原片，软件自动找出每个片段在原片中的确切位置，并直接生成可继续剪辑的工程文件。

**典型用户**：

- **影视解说 / 二创剪辑师**——素材回溯、对标分析、拉片复盘
- **剪辑团队**——从参考成片快速还原素材清单（EDL/工程文件）
- **版权与审核**——鉴定一段视频是否使用了某部影片、用了哪些片段
- **个人素材管理**——为庞大的原片库建立「成片 ↔ 源片」对照

## 二、工作流程（三步）

```
① 选择文件        ② 一键分析                ③ 复核与导出
原片 + 剪辑成片  →  镜头切分 → 特征检索     →  逐段预览比对
                   → 逐段反向定位               →  导出剪映 / Premiere 工程
```

1. **新建项目**，选择原片与剪辑成片；
2. **一键分析**：软件自动完成原片索引（一次性）、镜头切分、特征检索与逐段定位，全程 GPU 加速、进度可视、随时取消；
3. **结果复核**：每段给出原片区间 + 置信度（高/中/低），左右分屏直接比对画面；对有把握的结果可导出工程继续创作，拿不准的转人工。

---

## 三、核心能力

### 精准定位
- 每个片段给出**原片起止时间**，并按证据强度自动标注置信度（高/中/低/未定位），高置信结果可直接采用，低置信结果明确提示人工复核——不装懂、不静默出错。
- 真实影片基准测试：**场景级命中率 98%（136/139）**，镜头级严格命中 81%（113/139）；明确的「源片中不存在」内容（片头片尾、平台水印段）自动拒绝定位。

### 直接产出可用的剪辑工程
- **剪映**：导出草稿到剪映草稿目录，打开剪映即可看到按定位结果排好的时间线（含自动预转码的素材片段），直接继续微调；
- **Premiere**：导出 FCP7 XML，导入即生成时间线（辅以一键导入扩展面板）；
- 同时支持 CMX3600 EDL 与 JSON 结果数据，便于接入自动化流程。

### 快
- 原片索引一次构建、终身复用（2 小时影片约 7~12 分钟，GPU 加速）；
- 剪辑成片分析结果自动缓存——**同一成片重复定位约 2~4 分钟**；
- 全流程流水线并行 + 独立显卡（DirectML）加速。

### 全本地、可离线
- 视频与特征数据**全部留在本机**，不上传、不联网推理，适合未发行内容与版权敏感场景。

## 四、技术亮点（给技术决策者）

| 模块 | 说明 |
|---|---|
| 特征引擎 | DINOv2 ViT-S CLS 深度特征（518px），检索粒度 1fps，GPU 推理 |
| 硬件适配 | Windows AMD/Intel GPU（DirectML）/ CPU、macOS Apple Silicon（MPS），同一套架构自动选择 |
| 镜头切分 | 两级分层切分（粗采样找点 + 局部密帧精修边界）+ 白闪/亮度尖峰守卫 |
| 多证据定位 | 帧级证据聚类 + 场景指纹扩池 + 事件身份扩池 + patch 级重排，应对同场景多机位 |
| 置信体系 | 多信号置信评分（证据纯度/覆盖/稳定性），分级标注而非单一答案 |
| 工程化 | 桌面应用（Vue3 + Electron + Python FastAPI），索引与缓存全量持久化，幂等可重跑 |

## 五、诚实的边界

我们选择如实告知能力边界，而不是掩盖：

- **同场景相邻镜头**（一场连续对话戏内的机位切换）可能定位到相邻镜头，偏差通常在 ±15 秒内，画面主体相同；
- **高度相似的不同画面**（同机位重复拍摄、衍生版本内容）属于当前视觉特征的公认难点，此类结果会以较低置信度标注；
- 剪辑软件兼容性以剪映桌面版与 Adobe Premiere Pro 为准。
